# Proposed companion icons

Twelve original outline SVGs created for this working skill on 11 November 2026. These are not supplied or approved Resolvable icon masters and are not asserted to be extracted from the website or artwork. They interpret the stand's restrained outline treatment for new work. No third-party icon font or library is bundled. All use a 24-square viewBox, 1.75 stroke and currentColor. See references/iconography.md for usage and accessible labelling.
